# EMMA Frontend

Aplicación web de EMMA construida con Next.js (App Router) y Tailwind.

## Requisitos
- Node.js 20+

## Configuración rápida
1. Instalar dependencias: `npm install`
2. Crear archivo de entorno: `cp .env.example .env`
3. Configurar API (opcional): `NEXT_PUBLIC_API_URL` (por defecto usa `http://localhost:3001/api/v1`)
4. Ejecutar en desarrollo: `npm run dev`

## Build / Producción
- `npm run build`
- `npm run start`
